# Pernara güncellemeleri

Bu depoda sadece Pernara kasa uygulamasının **kurulum dosyaları** durur.
Kaynak kod ayrı ve gizli bir depodadır.

Kasa uygulaması (HillPOS) yeni sürümü buradan kendiliğinden bulur:
**Yönetim → Ayarlar → Güncelleme → Güncelle**.

Her sürüm bir "Release" olarak yayınlanır ve iki dosya içerir:

- `Pernara-Kurulum-<sürüm>.exe` — Windows kurulum dosyası
- `surum.json` — sürüm numarası, yenilikler ve kurulum dosyasının parmak izi (SHA-256)

Elle kurmak için: Releases bölümünden son sürümün `.exe` dosyasını indirip çalıştırın.
Veriler (`C:\Pernara`) kurulumdan etkilenmez.
